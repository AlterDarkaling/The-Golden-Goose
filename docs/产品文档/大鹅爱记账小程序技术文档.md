项目名称：大鹅爱记账个人财务管理系统

一、项目目标
使用微信小程序原生开发技术，实现专业的个人财务管理系统。基于传统会计准则，采用资产负债分类体系，通过现代化的界面设计和智能化的数据分析，帮助用户建立正确的财务管理理念，实现个人财富的科学管理。项目致力于打造一款既具备专业财务管理能力，又保持简洁易用特性的个人理财工具，让普通用户能够像企业一样进行精确的财务管理和分析。

二、技术角色 (明确分离)
前端框架: WXML + WXSS + JavaScript (ES6+) + 微信小程序原生API
- WXML：类似HTML的标记语言，支持数据绑定、条件渲染、列表渲染
- WXSS：类似CSS的样式语言，支持响应式单位rpx、选择器、动画
- JavaScript：ES6+语法，支持Promise、async/await、解构赋值等现代特性
- 微信API：包括存储、界面、设备、网络、媒体等丰富的原生能力

数据存储: 微信小程序本地存储 + JSON数据结构 + 数据备份机制
- 本地存储：wx.setStorageSync/wx.getStorageSync实现数据持久化
- 数据结构：设计标准化的JSON Schema确保数据一致性
- 备份恢复：支持完整备份、简化备份、CSV导出等多种格式

开发工具: 微信开发者工具 + 调试面板 + 真机调试
- 代码编辑：语法高亮、智能提示、代码格式化
- 调试功能：断点调试、网络监控、性能分析、存储查看
- 预览发布：二维码预览、真机调试、版本管理、提交审核

通信机制: 页面间通信 + 组件通信 + 全局状态管理
- 页面通信：通过页面参数、全局数据、事件机制实现数据传递
- 组件通信：父子组件通过properties和事件进行数据交互
- 状态管理：通过getApp()获取全局应用实例，实现跨页面状态共享

用户管理系统

- 头像管理：支持微信头像获取和自定义头像上传

资产负债管理系统

- 现金类资产：银行存款、现金、数字钱包、货币基金
- 短期理财资产：银行理财、短期国债、结构性存款

- 股票基金：股票、基金、ETF、可转债（按市值重估）

实物资产管理（2个子类）：
- 消费型资产：手机通讯、电脑数码、家用电器、交通工具（自动折旧）
- 增值型资产：房产、收藏品、贵金属（市场重估）
其他资产管理（2个子类）：
- 无形资产：软件版权、专利权、商标权（按期摊销）
- 预付资产：预付租金、预付保险费、会员费（时间分摊）

负债管理系统（3大类型7子类）：
- 流动负债：信用卡债务、短期借款、应付账款
- 长期负债：房贷、车贷、其他长期贷款（支持等额本息/等额本金计算）

财务分析与计算引擎
现金流分析：
- 月收入统计：工作收入、投资收益、其他收入分类汇总
- 月支出分析：生活支出、贷款还款、运营成本详细统计
- 净现金流：实时计算并提供财务健康状态评估

- 每日成本分析：计算物品每日使用成本，提供理性消费建议
- 更换提醒：基于折旧情况和使用效率提供更换建议
- 投资回报分析：计算资产投资回报率和回收周期

数据展示与筛选系统：
- 多维度排序：默认排序、按金额、按天数、按购买时间、按每日成本
- 智能筛选：支持一级分类、二级分类、物品状态、时间范围筛选
- 搜索功能：支持模糊搜索物品名称、备注信息
- 状态管理：10种物品状态（使用中、吃灰中、已卖出、已损坏等）

梦想储蓄罐功能：
- 目标设定：设置储蓄目标金额、时间期限、目标描述
- 进度跟踪：实时显示完成进度、剩余金额、预计完成时间

核心算法实现：
折旧计算引擎：
```javascript
// 直线法折旧计算
calculateDepreciation: function(originalValue, depreciationRate, usedDays) {
  const usedYears = usedDays / 365;
  const currentValue = Math.max(0, originalValue * (1 - depreciationRate * usedYears));
  const totalDepreciation = originalValue - currentValue;
  const dailyDepreciation = totalDepreciation / usedDays;
  
  return {
    currentValue: parseFloat(currentValue.toFixed(2)),
    totalDepreciation: parseFloat(totalDepreciation.toFixed(2)),
    dailyDepreciation: parseFloat(dailyDepreciation.toFixed(2)),
    depreciationRate: parseFloat((totalDepreciation / originalValue * 100).toFixed(2))
  };
}
```

现金流计算引擎：
```javascript
// 净现金流计算
calculateCashFlow: function(assets, liabilities) {
  const monthlyIncome = assets.reduce((sum, asset) => sum + (asset.monthlyIncome || 0), 0);
  const monthlyExpense = assets.reduce((sum, asset) => sum + (asset.monthlyCost || 0), 0);
  const loanPayments = liabilities.reduce((sum, liability) => sum + (liability.monthlyPayment || 0), 0);
  
  const netCashFlow = monthlyIncome - monthlyExpense - loanPayments;
  
  return {
    monthlyIncome: parseFloat(monthlyIncome.toFixed(2)),
    monthlyExpense: parseFloat(monthlyExpense.toFixed(2)),
    loanPayments: parseFloat(loanPayments.toFixed(2)),
    netCashFlow: parseFloat(netCashFlow.toFixed(2)),
    healthStatus: this.getFinancialHealthStatus(netCashFlow)
  };
}
```

贷款计算引擎：
```javascript
// 等额本息还款计算
calculateEqualPayment: function(principal, annualRate, months) {
  const monthlyRate = annualRate / 12 / 100;
  const monthlyPayment = principal * monthlyRate * Math.pow(1 + monthlyRate, months) / 
                        (Math.pow(1 + monthlyRate, months) - 1);
  const totalPayment = monthlyPayment * months;
  const totalInterest = totalPayment - principal;
  
  return {
    monthlyPayment: parseFloat(monthlyPayment.toFixed(2)),
    totalPayment: parseFloat(totalPayment.toFixed(2)),
    totalInterest: parseFloat(totalInterest.toFixed(2))
  };
}
```
