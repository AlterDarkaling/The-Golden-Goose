# 前端对接后端API指南

## 一、快速开始

### 1. 启用云端模式

编辑 `utils/apiClient.js`，修改配置：

```javascript
const API_CONFIG = {
  ENABLE_CLOUD: true,  // 改为 true 启用云端
  BASE_URL: 'https://your-domain.com/api',  // 修改为你的后端地址
  TIMEOUT: 10000
}
```

### 2. 替换存储调用

在需要的页面中，将 `StorageManager` 替换为 `SmartStorage`：

```javascript
// 原来的代码
const StorageManager = require('../../utils/storage.js')
const assets = StorageManager.getAssets()

// 改为（支持云端）
const { SmartStorage } = require('../../utils/apiClient.js')
const assets = await SmartStorage.getAssets()
```

```javascript
const { APIClient, API_CONFIG } = require('../../utils/apiClient.js')

// 在微信登录成功后
async onWechatLogin(e) {
  try {
    wx.showLoading({ title: '登录中...' })
    
    const { code } = await wx.login()
    
    if (API_CONFIG.ENABLE_CLOUD) {
      // 云端模式：调用后端API

      const result = await APIClient.wechatLogin(code, userInfo)

        // 保存用户信息
        StorageManager.saveUser(result.data.user)
        
        wx.hideLoading()
        wx.showToast({
          title: '登录成功',
          icon: 'success'
        })
        
        // 跳转到首页
        wx.switchTab({ url: '/pages/index/index' })
      }
    } else {
      // 本地模式：原有逻辑
      // ... 保持原有代码
    }
  } catch (error) {
    wx.hideLoading()
    wx.showToast({
      title: '登录失败',
      icon: 'none'
    })
  }
}
```

## 五、数据迁移功能

在个人中心页面添加"迁移到云端"功能：

```javascript
// pages/profile/profile.js
const { SmartStorage, API_CONFIG } = require('../../utils/apiClient.js')

Page({
  async migrateToCloud() {
    if (!API_CONFIG.ENABLE_CLOUD) {
      wx.showToast({
        title: '云端模式未启用',
        icon: 'none'
      })
      return
    }
    
    wx.showModal({
      title: '数据迁移',
      content: '确定要将本地数据迁移到云端吗？',
      success: async (res) => {
        if (res.confirm) {
          try {
            wx.showLoading({ title: '迁移中...' })
            
            const result = await SmartStorage.migrateLocalToCloud()
            
            wx.hideLoading()
            wx.showModal({
              title: '迁移成功',
              content: `已迁移 ${result.data.assetsCreated} 个资产，${result.data.liabilitiesCreated} 个负债`,
              showCancel: false
            })
          } catch (error) {
            wx.hideLoading()
            wx.showToast({
              title: '迁移失败',
              icon: 'none'
            })
          }
        }
      }
    })
  }
})
```

在 `pages/profile/profile.wxml` 中添加按钮：

### 步骤3：处理异步操作

因为API调用是异步的，需要将相关函数改为 `async/await`：

```javascript
// 原代码
loadData() {
  const assets = StorageManager.getAssets()
  this.setData({ assets })
}

// 新代码
async loadData() {
  try {
    const assets = await SmartStorage.getAssets()
    this.setData({ assets })
  } catch (error) {
    console.error('加载失败:', error)
  }
}
```

### 步骤4：添加错误处理

## 七、兼容性方案

如果你想保持本地模式和云端模式都可用：

```javascript
// 在app.js中添加全局配置
App({
  globalData: {
    storageMode: 'local'  // 'local' 或 'cloud'
  },
  
  switchToCloud() {
    this.globalData.storageMode = 'cloud'
    // 修改apiClient配置
    const { API_CONFIG } = require('./utils/apiClient.js')
    API_CONFIG.ENABLE_CLOUD = true
  }
})
```

## 九、注意事项

1. **备份数据**: 切换到云端模式前，务必备份本地数据
2. **Token管理**: Token默认7天过期，过期后需重新登录
3. **网络处理**: 在网络较差时添加重试机制
4. **数据同步**: 云端模式下，多设备数据会自动同步
5. **成本控制**: 注意API调用频率，避免不必要的请求

## 十、常见问题

### Q1: 切换到云端后本地数据怎么办？

A: 使用"迁移到云端"功能，一键上传本地数据。

### Q2: 如何回退到本地模式？

A: 修改 `API_CONFIG.ENABLE_CLOUD = false` 即可。

### Q3: Token过期怎么办？

A: 自动清除Token并提示用户重新登录。

### Q4: 如何处理网络错误？

A: SmartStorage会自动处理网络错误，并显示友好提示。

### Q5: 可以同时使用本地和云端吗？

A: 可以，本地作为缓存，云端作为主存储。需要自己实现同步逻辑。

## 十一、完整示例

完整的页面改造示例：

```javascript
// pages/index/index.js
const { SmartStorage, API_CONFIG } = require('../../utils/apiClient.js')

Page({
  data: {
    assets: [],
    liabilities: [],
    isCloudMode: false
  },
  
  onLoad() {
    this.setData({
      isCloudMode: API_CONFIG.ENABLE_CLOUD
    })
    this.loadData()
  },
  
  async loadData() {
    try {
      wx.showLoading({ title: '加载中...' })
      
      const [assets, liabilities] = await Promise.all([
        SmartStorage.getAssets(),
        SmartStorage.getLiabilities()
      ])
      
      this.setData({ assets, liabilities })
      this.calculateCashflow()
      
      wx.hideLoading()
    } catch (error) {
      console.error('加载失败:', error)
      wx.hideLoading()
      
      if (error.message === '未授权') {
        wx.showModal({
          title: '登录过期',
          content: '请重新登录',
          showCancel: false,
          success: () => {
            wx.reLaunch({ url: '/pages/login/login' })
          }
        })
      } else {
        wx.showToast({
          title: '加载失败',
          icon: 'none'
        })
      }
    }
  },
  
  async deleteAsset(e) {
    const { id } = e.currentTarget.dataset
    
    wx.showModal({
      title: '确认删除',
      content: '确定要删除这个资产吗？',
      success: async (res) => {
        if (res.confirm) {
          try {
            wx.showLoading({ title: '删除中...' })
            await SmartStorage.deleteAsset(id)
            
            // 重新加载数据
            await this.loadData()
            
            wx.hideLoading()
            wx.showToast({
              title: '删除成功',
              icon: 'success'
            })
          } catch (error) {
            wx.hideLoading()
            wx.showToast({
              title: '删除失败',
              icon: 'none'
            })
          }
        }
      }
    })
  }
})
```
