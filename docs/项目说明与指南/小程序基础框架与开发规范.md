# 大鹅爱记账 - 小程序基础框架与开发规范

## 一、项目概述

### 1.1 项目简介

大鹅爱记账是一款基于微信小程序平台开发的智能财务管理应用，采用传统会计准则，为个人用户提供专业的资产负债管理、折旧计算、贷款分析等功能。

### 1.2 技术选型

| 类别 | 技术方案 |
| --- | --- |
| 前端框架 | 微信小程序原生开发 |
| 开发语言 | JavaScript / WXML / WXSS |
| 数据存储 | 本地存储（wx.setStorageSync） |
| 后端服务 | Node.js + Express |
| 数据库 | MySQL 8.0 |
| ORM框架 | Sequelize 6.x |

### 1.3 环境要求

- 微信开发者工具 1.06.0 及以上
- 基础库版本 2.19.4 及以上
- Node.js 16.0.0 及以上（后端服务）

```javascript
// 1. 统一使用同步API
wx.setStorageSync(key, data)
const data = wx.getStorageSync(key)

// 2. 数据操作封装
class StorageManager {
  static save(key, data) {
    try {
      wx.setStorageSync(key, {
        data: data,
        updateTime: new Date().toISOString()
      })
      return true
    } catch (error) {
      console.error('存储失败:', error)
      return false
    }
  }
  
  static get(key, defaultValue = null) {
    try {
      const result = wx.getStorageSync(key)
      return result ? result.data : defaultValue
    } catch (error) {
      console.error('读取失败:', error)
      return defaultValue
    }
  }
}
```

### 4.4 错误处理规范

```javascript
// 1. 统一错误处理格式
function handleError(error, context = '') {
  console.error(`[${context}] 错误:`, error)
  
  wx.showToast({
    title: '操作失败，请重试',
    icon: 'none',
    duration: 2000
  })
}

// 2. 异步操作错误处理
async function saveAsset(assetData) {
  try {
    const result = await StorageManager.save('assets', assetData)
    if (!result) {
      throw new Error('保存失败')
    }
    return { success: true, data: result }
  } catch (error) {
    handleError(error, 'saveAsset')
    return { success: false, error: error.message }
  }
}

// 3. 输入验证
function validateAssetData(data) {
  const errors = []
  
  if (!data.name || data.name.trim() === '') {
    errors.push('资产名称不能为空')
  }
  
  if (data.initialValue < 0) {
    errors.push('初始价值不能为负数')
  }
  
  return {
    valid: errors.length === 0,
    errors: errors
  }
}
```

## 五、核心模块说明

### 5.1 折旧计算引擎

位置：`utils/depreciation.js`

主要功能：
- 预设折旧率管理
- 资产当前价值计算
- 未来价值预测
- 智能提示生成

核心算法：
```
当前净值 = 原值 * (1 - 年折旧率) ^ 使用年数
月均折旧 = 累计折旧 / (使用年数 * 12)
```

### 5.2 贷款计算器

位置：`utils/loanCalculator.js`

主要功能：
- 等额本息计算
- 等额本金计算
- 还款计划生成
- 提前还款分析

### 5.3 财务存储管理

主要功能：
- 资产数据管理
- 负债数据管理
- 净资产计算
- 现金流分析
- 财务健康报告生成
