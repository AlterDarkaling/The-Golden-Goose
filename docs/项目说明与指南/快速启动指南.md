# ⚡ 快速启动指南

## 🎯 启动后端服务

### 方式1：使用启动脚本（最简单）✨

**双击运行**：`启动后端服务.bat`

就这么简单！脚本会自动：
1. 检查是否安装依赖
2. 启动后端服务

---

### 方式2：手动命令

#### PowerShell 命令

```powershell
# 进入backend目录
cd "E:\Code\WeChatProject\The Golden Goose Demo2\backend"

# 首次运行需要安装依赖（只需执行一次）
npm install

# 启动服务
npm run dev
```

#### 或者使用绝对路径一步到位

```powershell
cd "E:\Code\WeChatProject\The Golden Goose Demo2\backend"; npm run dev
```

## ⚠️ 常见错误

### 错误1：找不到 package.json

```
npm error enoent Could not read package.json
```

**原因**：在错误的目录运行了npm命令

**解决**：确保在 `backend` 目录中运行

```powershell
# 检查当前目录
pwd
# 应该显示：E:\Code\WeChatProject\The Golden Goose Demo2\backend

# 如果不对，重新进入
cd "E:\Code\WeChatProject\The Golden Goose Demo2\backend"
```

### 错误2：端口被占用

```
Error: listen EADDRINUSE :::3000
```

**解决方案A**：杀死占用端口的进程
```powershell
# 查找占用3000端口的进程
netstat -ano | findstr :3000

# 记下PID，然后杀死进程（假设PID是1234）
taskkill /PID 1234 /F
```

**解决方案B**：修改端口
```
编辑 backend/.env 文件
将 PORT=3000 改为 PORT=3001
```

### 错误3：依赖未安装

```
Error: Cannot find module 'express'
```

**解决**：安装依赖
```powershell
cd "E:\Code\WeChatProject\The Golden Goose Demo2\backend"
npm install
```

### 错误4：MySQL连接失败

```
Access denied for user 'root'@'localhost'
```

**解决步骤**：

1. 检查MySQL是否启动
```powershell
# 查看MySQL服务状态
Get-Service -Name MySQL*
```

2. 检查密码是否正确
```
编辑 backend/.env 文件
修改 DB_PASSWORD=你的正确密码
```

3. 测试连接
```powershell
mysql -u root -p
# 输入密码，能进入就说明密码正确
```

## 💡 小技巧

### 自动重启（推荐）

安装 nodemon 后代码修改会自动重启：

```powershell
# 全局安装 nodemon（只需一次）
npm install -g nodemon

# 使用 nodemon 启动
cd backend
nodemon app.js
```

### VSCode 集成终端

如果你用VSCode：
1. 打开项目
2. 按 Ctrl + ` 打开终端
3. 运行命令即可
