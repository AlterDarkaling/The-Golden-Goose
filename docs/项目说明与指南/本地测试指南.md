## 🐛 常见问题排查

### 问题1：保存时没有后端日志

**可能原因**：
- apiClient.js 的 `ENABLE_CLOUD` 还是 false
- 小程序没有重新编译
- 后端服务没有运行

**解决**：
```javascript
// 1. 检查 utils/apiClient.js
ENABLE_CLOUD: true,  // 必须是 true

// 2. 重新编译小程序（Ctrl+B）

// 3. 确认后端运行中
// 查看PowerShell窗口是否显示：
🚀 服务器运行在 http://localhost:3000
```

### 问题2：小程序报错 "request:fail"

**可能原因**：未开启"不校验合法域名"

**解决**：
1. 微信开发者工具 → 右上角 **详情**
2. **本地设置** 标签
3. ✅ 勾选 **"不校验合法域名..."**

### 问题3：后端报 401 未授权

**原因**：Token认证失败

**解决**：
修改 `backend/controllers/authController.js` 的测试代码（暂时跳过Token验证）：

```javascript
// 临时测试方案：创建假Token
exports.wechatLogin = async (req, res, next) => {
  try {
    // 简化版本：不验证微信code，直接创建用户
    let user = await User.findOne({ where: { openid: 'test_openid_123' } })
    
    if (!user) {
      user = await User.create({
        openid: 'test_openid_123',
        nickname: '测试用户',
        wechat_avatar: ''
      })
    }
    
    const token = generateToken(user.id)
    
    res.json({
      success: true,
      message: '登录成功',
      data: { token, user }
    })
  } catch (error) {
    next(error)
  }
}
```

### 问题4：数据保存但看不到

**原因**：后端返回的数据格式与前端不一致

**解决**：已添加字段映射，应该已解决
