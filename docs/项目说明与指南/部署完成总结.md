## 🚀 快速开始指南

### 第一步：准备服务器

**推荐配置**：
- 服务商：腾讯云轻量应用服务器
- 配置：1核2G，40GB SSD
- 系统：Ubuntu 20.04 LTS
- 成本：60元/月

### 第二步：自动部署

```bash
# 1. 连接服务器
ssh root@your_server_ip

# 2. 上传部署脚本
scp backend/scripts/quick-deploy.sh root@your_server_ip:/root/

# 3. 运行部署脚本
chmod +x /root/quick-deploy.sh
sudo bash /root/quick-deploy.sh
```

脚本会自动完成：
- ✅ 安装Node.js、MySQL、PM2
- ✅ 配置数据库
- ✅ 安装依赖
- ✅ 启动服务

### 第三步：配置环境变量

编辑 `/var/www/golden-goose/backend/.env`：

```env
# 必须配置
WECHAT_APPID=你的小程序AppID
WECHAT_SECRET=你的小程序Secret

# 可选配置
ALLOWED_ORIGINS=https://your-domain.com
```

重启服务：
```bash
pm2 restart golden-goose-api
```

### 第四步：配置前端

编辑小程序 `utils/apiClient.js`：

```javascript
const API_CONFIG = {
  ENABLE_CLOUD: true,  // 启用云端模式
  BASE_URL: 'http://your_server_ip:3000/api',  // 你的服务器地址
  TIMEOUT: 10000
}
```

### 第五步：测试

访问健康检查接口：
```
http://your_server_ip:3000/health
```

应该返回：
```json
{
  "status": "ok",
  "timestamp": "2024-11-03T...",
  "version": "1.0.0"
}
```

## 💡 使用场景对比

### 本地模式（当前）
```
用户 → 小程序 → 本地存储
```
✅ 优点：免费、隐私、快速  
❌ 缺点：无法多设备同步

### 云端模式（部署后）
```
用户 → 小程序 → 后端API → MySQL
```
✅ 优点：多设备同步、数据安全、可扩展  
❌ 缺点：需要服务器（60元/月）

### 混合模式（推荐）
```
用户 → 小程序 → 本地缓存 + 云端同步
```
✅ 优点：兼具两者优势  
❌ 缺点：开发复杂度稍高

## 🐛 常见问题排查

### 1. 服务无法启动
```bash
# 检查端口占用
sudo lsof -i :3000

# 查看错误日志
pm2 logs golden-goose-api --err

# 检查环境变量
cat /var/www/golden-goose/backend/.env
```

### 2. 数据库连接失败
```bash
# 检查MySQL状态
sudo systemctl status mysql

# 测试连接
mysql -u goose_user -p golden_goose
```

### 3. 小程序无法连接后端
- ✅ 检查服务器IP是否正确
- ✅ 检查防火墙是否开放3000端口
- ✅ 检查小程序合法域名配置

### 4. Token认证失败
- ✅ 检查JWT_SECRET是否一致
- ✅ 检查Token是否过期
- ✅ 清除小程序缓存重新登录
