## 🔧 核心技术点

### 1. 字段名自动映射
```javascript
// 前端驼峰命名
{
  categoryL1: 'current_assets',
  initialValue: 1000
}

// 自动转换为后端下划线命名
{
  category_l1: 'current_assets',
  initial_value: 1000
}

// 返回时再转回驼峰
```

### 2. 开发环境简化认证
```javascript
// 开发环境：自动创建测试用户
// 生产环境：需要JWT Token
```

### 3. SmartStorage 智能存储
```javascript
// 一行配置切换模式
ENABLE_CLOUD: true/false

// 自动选择本地或云端
await SmartStorage.saveAsset(data)
```

## 🐛 常见问题

### Q1: 如何关闭详细的SQL日志？

编辑 `backend/config/database.js`：
```javascript
logging: false  // 改为 false
```

### Q2: 如何切回本地存储模式？

编辑 `utils/apiClient.js`：
```javascript
ENABLE_CLOUD: false  // 改回 false
```

### Q3: 如何清空数据库重新测试？

```sql
mysql -u root -p
USE golden_goose;
TRUNCATE TABLE assets;
TRUNCATE TABLE liabilities;
DELETE FROM users WHERE openid = 'dev_test_user';
```

### Q4: 如何部署到生产环境？

参考：
- `backend/DEPLOYMENT.md` - 详细部署文档
