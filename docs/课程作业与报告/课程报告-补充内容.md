## 3 系统功能设计与实现

### 3.1 用户登录

#### 3.1.1 设计思路

用户登录采用微信小程序授权登录方式，流程如下：

```
登录流程：
1. 用户打开小程序，进入欢迎页
2. 点击"开始使用"按钮
3. 调用wx.login()获取临时登录凭证code
4. （可选）调用wx.getUserProfile()获取用户信息
5. 将code和用户信息发送到后端
6. 后端调用微信API验证code，获取openid
7. 后端生成JWT token返回给前端
8. 前端保存token，跳转到首页
9. 后续请求携带token进行身份验证
```

**设计要点：**
- 采用JWT token进行身份认证
- 用户信息本地缓存，减少网络请求
- 支持本地模式（无需后端）和云端模式

#### 3.1.2 代码实现

**前端代码（pages/login/login.js）**

```javascript
// 微信登录
handleLogin() {
  wx.login({
    success: (res) => {
      if (res.code) {
        // 获取用户信息
        wx.getUserProfile({
          desc: '用于完善用户资料',
          success: (userRes) => {
            const { nickName, avatarUrl } = userRes.userInfo;
            
            // 保存用户信息到本地
            wx.setStorageSync('userInfo', {
              nickname: nickName,
              avatar: avatarUrl
            });
            
            // 跳转到首页
            wx.switchTab({
              url: '/pages/index/index'
            });
          },
          fail: () => {
            // 用户拒绝授权，使用默认信息
            this.useDefaultUser();
          }
        });
      }
    }
  });
}
```

**后端代码（controllers/authController.js）**

```javascript
// 微信登录接口
exports.wechatLogin = async (req, res) => {
  try {
    const { code, userInfo } = req.body;
    
    // 调用微信API获取openid
    const wxResult = await wechatService.code2Session(code);
    const { openid } = wxResult;
    
    // 查找或创建用户
    let user = await User.findOne({ where: { openid } });
    if (!user) {
      user = await User.create({
        openid,
        nickname: userInfo.nickname,
        avatar: userInfo.avatarUrl
      });
    }
    
    // 生成JWT token
    const token = jwt.sign(
      { userId: user.id, openid: user.openid },
      process.env.JWT_SECRET,
      { expiresIn: '7d' }
    );
    
    res.json({
      success: true,
      data: { token, user }
    });
  } catch (error) {
    res.status(500).json({
      success: false,
      message: '登录失败'
    });
  }
};
```

### 3.2 资产管理

#### 3.2.1 设计思路

资产管理是系统的核心功能，支持添加、编辑、删除、查看资产。

**功能设计：**
1. **资产列表**：首页展示所有资产，支持筛选和排序
2. **添加资产**：分步骤引导用户输入资产信息
3. **编辑资产**：修改资产信息，自动重新计算价值
4. **删除资产**：二次确认后删除
5. **资产详情**：展示资产完整信息和价值变化

**计算逻辑：**
- 消费性资产：自动折旧计算
  ```
  当前价值 = 原值 × (1 - 折旧率)^使用年限
  ```
- 金融资产：按市值计量
  ```
  当前价值 = 持有数量 × 当前价格
  浮动盈亏 = 当前价值 - 成本价值
  ```
- 理财产品：按成本+应计利息
  ```
  应计利息 = 本金 × 年利率 × 已持有天数 / 365
  当前价值 = 本金 + 应计利息
  ```

#### 3.2.2 代码实现

**添加资产（pages/edit/edit.js）**

```javascript
// 保存资产
saveAsset() {
  const assetData = {
    id: `asset_${Date.now()}`,
    name: this.data.name,
    categoryL1: this.data.categoryL1,
    categoryL2: this.data.categoryL2,
    initialValue: this.data.initialValue,
    createDate: this.data.createDate,
    monthlyIncome: this.data.monthlyIncome || 0,
    monthlyOperatingCost: this.data.monthlyOperatingCost || 0,
    status: 'active',
    createTime: new Date().toISOString()
  };
  
  // 计算当前价值
  if (this.isConsumerAsset()) {
    const depreciationRate = this.getDepreciationRate();
    assetData.depreciationRate = depreciationRate;
    assetData.currentValue = this.calculateCurrentValue(
      assetData.initialValue,
      assetData.createDate,
      depreciationRate
    );
  } else {
    assetData.currentValue = assetData.initialValue;
  }
  
  // 保存到本地存储
  const assets = wx.getStorageSync('assets') || [];
  assets.push(assetData);
  wx.setStorageSync('assets', assets);
  
  // 返回首页
  wx.navigateBack();
}

// 计算当前价值（折旧）
calculateCurrentValue(originalValue, purchaseDate, depreciationRate) {
  const usageYears = this.calculateUsageYears(purchaseDate);
  return originalValue * Math.pow(1 - depreciationRate, usageYears);
}

// 计算使用年限
calculateUsageYears(purchaseDate) {
  const now = new Date();
  const purchase = new Date(purchaseDate);
  const diffTime = Math.abs(now - purchase);
  const diffDays = Math.ceil(diffTime / (1000 * 60 * 60 * 24));
  return diffDays / 365;
}
```

**资产列表（pages/index/index.js）**

```javascript
// 加载资产列表
loadAssets() {
  const assets = wx.getStorageSync('assets') || [];
  const liabilities = wx.getStorageSync('liabilities') || [];
  
  // 更新所有资产的当前价值
  const updatedAssets = assets.map(asset => {
    if (asset.depreciationRate) {
      asset.currentValue = this.calculateCurrentValue(
        asset.initialValue,
        asset.createDate,
        asset.depreciationRate
      );
    }
    return asset;
  });
  
  // 计算财务指标
  const totalAssets = updatedAssets.reduce((sum, a) => sum + a.currentValue, 0);
  const totalLiabilities = liabilities.reduce((sum, l) => sum + l.currentAmount, 0);
  const netWorth = totalAssets - totalLiabilities;
  
  this.setData({
    assets: updatedAssets,
    liabilities,
    totalAssets,
    totalLiabilities,
    netWorth
  });
}
```

### 3.3 负债管理

#### 3.3.1 设计思路

负债管理功能与资产管理类似，但增加了贷款计算功能。

**核心功能：**
1. **贷款计算器**：支持等额本息和等额本金两种方式
2. **还款计划**：自动生成每期还款明细
3. **利息计算**：实时计算已付利息和剩余利息
4. **关联资产**：贷款购买的资产可以关联

**贷款计算公式：**

等额本息月供计算：
```
月供 = 本金 × 月利率 × (1 + 月利率)^还款月数 / [(1 + 月利率)^还款月数 - 1]
```

等额本金月供计算：
```
每月本金 = 贷款本金 / 还款月数
每月利息 = 剩余本金 × 月利率
月供 = 每月本金 + 每月利息
```

#### 3.3.2 代码实现

**贷款计算器（utils/loanCalculator.js）**

```javascript
class LoanCalculator {
  // 等额本息计算
  static calculateEqualInstallment(principal, annualRate, months) {
    const monthlyRate = annualRate / 12;
    const monthlyPayment = principal * monthlyRate * 
      Math.pow(1 + monthlyRate, months) / 
      (Math.pow(1 + monthlyRate, months) - 1);
    
    const totalPayment = monthlyPayment * months;
    const totalInterest = totalPayment - principal;
    
    return {
      monthlyPayment: monthlyPayment.toFixed(2),
      totalPayment: totalPayment.toFixed(2),
      totalInterest: totalInterest.toFixed(2)
    };
  }
  
  // 等额本金计算
  static calculateEqualPrincipal(principal, annualRate, months) {
    const monthlyRate = annualRate / 12;
    const monthlyPrincipal = principal / months;
    
    let totalPayment = 0;
    let remainingPrincipal = principal;
    const schedule = [];
    
    for (let i = 1; i <= months; i++) {
      const monthlyInterest = remainingPrincipal * monthlyRate;
      const monthlyPayment = monthlyPrincipal + monthlyInterest;
      totalPayment += monthlyPayment;
      remainingPrincipal -= monthlyPrincipal;
      
      schedule.push({
        period: i,
        principal: monthlyPrincipal.toFixed(2),
        interest: monthlyInterest.toFixed(2),
        payment: monthlyPayment.toFixed(2),
        remaining: remainingPrincipal.toFixed(2)
      });
    }
    
    return {
      schedule,
      totalPayment: totalPayment.toFixed(2),
      totalInterest: (totalPayment - principal).toFixed(2)
    };
  }
}

module.exports = LoanCalculator;
```

```javascript
// 生成财务报告
generateReport() {
  const assets = wx.getStorageSync('assets') || [];
  const liabilities = wx.getStorageSync('liabilities') || [];
  
  // 计算净资产
  const totalAssets = assets.reduce((sum, a) => sum + a.currentValue, 0);
  const totalLiabilities = liabilities.reduce((sum, l) => sum + l.currentAmount, 0);
  const netWorth = totalAssets - totalLiabilities;
  
  // 计算现金流
  const monthlyIncome = assets.reduce((sum, a) => sum + (a.monthlyIncome || 0), 0);
  const monthlyExpense = assets.reduce((sum, a) => sum + (a.monthlyOperatingCost || 0), 0);
  const monthlyLoanPayment = liabilities.reduce((sum, l) => sum + (l.monthlyPayment || 0), 0);
  const netCashFlow = monthlyIncome - monthlyExpense - monthlyLoanPayment;
  
  // 财务健康状态
  let financialHealth = '';
  if (netCashFlow > 500) {
    financialHealth = '优秀';
  } else if (netCashFlow > 0) {
    financialHealth = '健康';
  } else if (netCashFlow > -200) {
    financialHealth = '紧张';
  } else {
    financialHealth = '危险';
  }
  
  this.setData({
    netWorth,
    totalAssets,
    totalLiabilities,
    monthlyIncome,
    monthlyExpense,
    monthlyLoanPayment,
    netCashFlow,
    financialHealth
  });
}
```
