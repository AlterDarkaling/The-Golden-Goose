# 金鹅理财小程序 - 简历项目经历

## 项目描述

**金鹅理财小程序**（原名：大鹅爱记账）是一款基于微信小程序平台开发的个人财务管理应用，区别于传统记账软件，本项目基于企业级会计准则构建，专注于净资产管理和现金流分析。系统实现了资产负债表管理、智能折旧计算、贷款成本分析和财务健康诊断等功能，帮助用户从"记账"升级到"理财"，实现财富增长可视化。

## 技术栈

- **前端框架**：微信小程序原生开发（WXML + WXSS + JavaScript）
- **状态管理**：自研轻量级状态管理方案
- **数据存储**：微信小程序本地存储 + 数据导出功能
- **计算引擎**：自研会计引擎 + 折旧计算器 + 贷款计算器
- **UI组件**：自定义组件库 + 微信原生组件
- **开发工具**：微信开发者工具 + VS Code
- **版本控制**：Git

## 架构设计

### 1. 多层架构设计

项目采用经典的三层架构设计，实现了关注点分离和代码复用：

- **表示层**：WXML + WXSS 实现界面展示，采用组件化开发
- **业务逻辑层**：JavaScript 实现业务逻辑，包含多个核心计算引擎
- **数据层**：基于微信小程序本地存储实现的数据持久化方案

### 2. 核心技术模块

#### 2.1 会计引擎 (AccountingEngine)

基于传统会计准则实现的计算引擎，支持：

- **资产计量**：实现了四大类资产（流动资产、金融资产、实物资产、其他资产）的专业计量规则
- **负债计量**：支持三大类负债（流动负债、长期负债、其他负债）的计量和利息计算
- **净资产计算**：实时计算用户净资产，提供财富增长可视化
- **现金流分析**：基于收入、支出、贷款月供和资产折旧摊销实现现金流预测

```javascript
// 净资产计算示例
calculateNetWorth() {
  const totalAssets = this.calculateTotalAssetValue();
  const totalLiabilities = this.calculateTotalLiabilityValue();
  return {
    netWorth: totalAssets - totalLiabilities,
    totalAssets,
    totalLiabilities
  };
}
```

#### 2.2 折旧引擎 (DepreciationEngine)

实现了基于会计准则的资产折旧计算：

- **多种折旧方法**：支持直线法、双倍余额递减法等多种折旧方式
- **预设折旧率**：针对不同资产类别（电子产品、家具家电、交通工具等）设置差异化折旧率
- **残值计算**：支持设定残值率，更准确计算资产价值
- **折旧提示**：基于折旧率和使用时间，提供智能购买建议

```javascript
// 折旧计算示例
calculateCurrentValue(originalValue, purchaseDate, depreciationRate) {
  const usageYears = this.calculateUsageYears(purchaseDate);
  return originalValue * Math.pow(1 - depreciationRate, usageYears);
}
```

#### 2.3 贷款计算器 (LoanCalculator)

实现了专业的贷款计算功能：

- **多种还款方式**：支持等额本息和等额本金两种主流还款方式
- **利息拆分**：精确计算每期还款中的本金和利息构成
- **提前还款**：支持部分提前还款和全部提前还款计算
- **成本分析**：计算贷款总成本，辅助用户做出财务决策

```javascript
// 等额本息月供计算
calculateEqualInstallment(principal, annualRate, months) {
  const monthlyRate = annualRate / 12;
  return principal * monthlyRate * Math.pow(1 + monthlyRate, months) / 
         (Math.pow(1 + monthlyRate, months) - 1);
}
```

#### 2.4 财务存储管理器 (FinancialStorage)

设计了高效的数据管理方案：

- **分类存储**：将用户信息、资产、负债等数据分类存储
- **数据一致性**：实现了事务机制，确保数据操作的原子性
- **缓存优化**：采用内存缓存 + 持久化存储的双层结构，提升性能
- **数据导出**：支持将财务数据导出为标准格式，方便备份和分析

```javascript
// 事务示例
static transaction(callback) {
  try {
    const result = callback();
    return { success: true, data: result };
  } catch (error) {
    console.error('Transaction failed:', error);
    return { success: false, error };
  }
}
```

### 3. 性能优化

- **懒加载**：采用小程序分包加载，减少首次启动时间
- **虚拟列表**：针对长列表数据，实现了虚拟滚动，提升渲染性能
- **计算缓存**：对复杂计算结果进行缓存，避免重复计算
- **按需渲染**：实现了条件渲染和组件复用，减少页面重绘

### 4. 安全设计

- **本地存储**：所有敏感财务数据仅保存在用户设备本地
- **数据加密**：对关键财务数据进行加密存储
- **权限控制**：严格控制小程序权限申请，保护用户隐私
