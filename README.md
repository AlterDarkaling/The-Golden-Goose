> 基于传统会计准则和现金流管理理念，打造的智能个人财务管理小程序

## 🎯 项目简介

**会下金蛋的鹅**是一款基于微信小程序开发的智能财务管理应用，严格遵循**传统会计准则**，采用专业的资产负债分类体系（4大资产类型12子类 + 3大负债类型7子类），为个人用户提供企业级的财务管理精度。

### 💡 核心理念（传统会计准则）
- **流动资产**：现金类资产 + 短期理财资产（按实际金额/应计利息计量）
- **金融资产**：股票/基金 + 固定收益（按市值重估/票面价值计量）  
- **实物资产**：消费型资产（自动折旧）+ 增值型资产（市场重估）
- **其他资产**：无形资产（按期摊销）+ 预付资产（时间分摊）
- **负债分离**：流动负债 + 长期负债 + 其他负债（本金利息完全分离）

## ✨ 核心功能

### 🏠 智能首页
- **财务概览**：实时净资产、月现金流、财务健康状态
- **现金流分析**：月收入、月支出、净现金流动态显示
- **智能筛选**：多维度排序（默认/金额/天数/购买时间/每日成本）
- **多级分类**：资产负债二级分类筛选
- **状态管理**：10种物品状态（使用中/吃灰中/已卖出等）

### 💰 资产管理系统（传统会计准则）

#### 💵 流动资产
- **现金类资产**：银行存款、现金、数字钱包、货币基金
  - **计量规则**：按实际金额计量，支持多账户汇总
- **短期理财资产**：银行理财、短期国债、结构性存款
  - **计量规则**：按成本入账，自动计算应计利息
  - **公式**：每日应计利息 = 票面金额 × 年利率 ÷ 365

#### 📈 金融资产
- **股票/基金类**：A股、港股、美股、ETF、公募基金
  - **计量规则**：按市值重估，区分成本价与当前价
  - **自动计算**：浮动盈亏、总市值、盈亏比例
- **固定收益类**：企业债券、国债、定期存款、大额存单
  - **计量规则**：按票面价值计量，按月计提利息

#### 🏠 实物资产
- **消费型资产**（自动折旧）：手机电脑、家电家具、汽车衣物
  - **折旧率设置**：手机40%、家电20%、家具10%、汽车20%、衣物50%
  - **计算公式**：月折旧额 = 原值 × 年折旧率 ÷ 12
  - **资产净值**：原值 - 累计折旧
- **增值型资产**（市场重估）：房产、贵金属、收藏品
  - **计量规则**：按市场估值重估，记录维护成本

#### 📋 其他资产
- **无形资产**：专利权、著作权、商标权、软件使用权
  - **摊销规则**：按有效期摊销，月摊销额 = 原值 ÷ 有效期月数
- **预付资产**：预付房租、健身卡、保险费
  - **摊销规则**：按时间比例分摊，自动生成摊销计划

### 💳 负债管理系统（传统会计准则）

#### 💳 流动负债
- **信用卡负债**：信用卡账单、分期付款、现金透支
  - **计量规则**：按账单日记录应还总额，区分已出账单与未出账单
  - **特殊功能**：账单日提醒、最低还款额计算
- **短期借款**：花呗借呗、微粒贷、亲友借款、现金贷
  - **计量规则**：按剩余本金计量，按日计息
  - **公式**：每日利息 = 剩余本金 × 日利率

#### 🏠 长期负债
- **房贷**：住房贷款、商业贷款、公积金贷款
  - **双模式计算**：等额本息 + 等额本金
  - **自动计算**：月供、剩余本金、已付利息、总利息成本
- **车贷/消费贷**：汽车贷款、装修贷款、教育贷款
  - **关联功能**：自动关联贷款购买的资产
  - **风险提示**：资产折旧速度 vs 贷款偿还速度对比

#### 📄 其他负债
- **应付款项**：水电燃气费、通讯费、医疗账单
  - **计量规则**：按账单金额记录，支付后核销
  - **提醒功能**：到期日提醒、自动核销
- **预收款项**：预收租金、预收会员费
  - **计量规则**：按时间比例确认收入，自动生成收入确认表

#### 🔧 核心计算规则
- **净资产公式**：总资产净值 - 总负债剩余本金
- **现金流公式**：月收入 - (月支出 + 贷款月供 + 资产折旧摊销)
- **资产负债分离**：贷款购买资产时，资产价值与贷款负债完全独立记录

### 核心算法

#### 折旧计算引擎
```javascript
// 当前净值计算
currentValue = originalValue × (1 - depreciationRate)^usageYears

// 月均折旧额
monthlyDepreciation = totalDepreciation / (usageYears × 12)

// 智能提示生成
if (depreciationRatio > 50%) {
  tip = "该物品已贬值50%+，建议考虑更换时机"
}
```

#### 现金流计算
```javascript
// 月现金流计算  
netCashFlow = monthlyIncome - monthlyExpense - loanPayments - operatingCosts

// 财务健康状态
if (netCashFlow > 500) status = "优秀"
else if (netCashFlow > 0) status = "健康"  
else if (netCashFlow > -200) status = "紧张"
else status = "危险"
```

## 🚀 快速开始

### 环境要求
- 微信开发者工具 1.06.0+
- 基础库 2.19.4+

### 安装步骤
1. **克隆项目**
   ```bash
   git clone https://github.com/yourrepo/golden-goose-mini.git
   cd golden-goose-mini
   ```

2. **导入项目**
   - 打开微信开发者工具
   - 选择"导入项目"
   - 选择项目目录

3. **首次使用**
   - 点击"开始使用"进入应用
   - 系统自动创建示例数据
   - 开始添加你的资产和负债

### 使用指南

#### 添加消费性资产
1. 首页点击"+"按钮 → 选择"添加资产"
2. 选择"消费性资产"分类
3. 填写基本信息：
   - 名称：如"MacBook Pro"
   - 二级分类：电脑数码
   - 购买价格：¥12,999
   - 购买日期：选择实际日期
   - 月运营成本：¥0（可选）
4. 系统自动计算折旧并显示当前价值

#### 贷款购买记录
1. 同时添加资产和负债记录
2. 资产按原值记录
3. 负债记录贷款信息
4. 系统自动分离计算，互不影响
