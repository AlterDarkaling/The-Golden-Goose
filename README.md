# 金鹅理财 - 个人财务管理小程序

## 项目简介

金鹅理财是一款基于微信小程序开发的个人财务管理应用，遵循《富爸爸穷爸爸》的理财理念，帮助用户区分资产和负债，实现个人净资产的科学管理。

## 核心功能

### 🏠 首页概览
- **个人信息栏**：显示净资产、用户头像、每日成本、资产数量、负债数量、每日收益
- **功能栏**：搜索、排序、分类筛选、状态筛选（只占一行）
- **数据列表**：展示所有资产和负债项目，支持点击查看详情

### 💰 资产管理
- 支持多种资产分类：投资理财、经营性资产、知识产权、房地产等
- 记录初始价值、当前价值、每日收益、年化收益率
- 基于《富爸爸穷爸爸》理念：能产生现金流的才是真正的资产

### 💳 负债管理
- 支持多种负债分类：消费贷款、经营性负债、信用卡、房贷等
- 记录初始金额、当前金额、每日成本、年化利率
- 帮助用户识别真正的负债，避免消费陷阱

### 👤 用户系统
- 本地用户注册/登录
- 支持头像上传（相册选择/拍照）
- 完全基于本地存储，保护用户隐私

### 📊 数据统计
- 实时计算净资产
- 每日成本统计
- 每日收益统计
- 资产和负债数量统计

## 使用方法

### 首次使用
1. 在微信开发者工具中导入项目
2. 使用默认账号登录：
   - 用户名：`demo`
   - 密码：`123456`

### 添加资产
1. 在首页点击"+ 资产"按钮
2. 填写资产信息：
   - 名称：如"股票投资"
   - 分类：选择资产类型
   - 初始价值：投入的金额
   - 每日收益：预期每日收益
   - 年化收益率：预期年化收益

### 添加负债
1. 在首页点击"+ 负债"按钮
2. 填写负债信息：
   - 名称：如"信用卡消费"
   - 分类：选择负债类型
   - 初始金额：欠款金额
   - 每日成本：每日利息成本
   - 年化利率：年化利率

### 管理数据
- **查看详情**：点击列表项查看详细信息
- **编辑**：在详情页点击"编辑"按钮
- **删除**：在详情页点击"删除"按钮
- **搜索**：使用搜索栏快速查找
- **筛选**：按分类、状态等条件筛选

## 理财理念

### 什么是资产？
根据《富爸爸穷爸爸》的理念，**资产是能够产生现金流入的东西**：
- ✅ 股票投资（产生股息）
- ✅ 出租房产（产生租金）
- ✅ 经营性资产（产生利润）
- ✅ 知识产权（产生版税）

### 什么是负债？
**负债是产生现金流出或需要持续支出的东西**：
- ❌ 消费贷款（产生利息支出）
- ❌ 信用卡欠款（产生利息）
- ❌ 房贷（产生利息支出）
- ❌ 消费性车辆（产生维护费用）

### 关键区别
- **资产**：把钱放进你的口袋
- **负债**：把钱从你的口袋拿走
